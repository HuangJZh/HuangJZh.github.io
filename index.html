Junzhi Huang

Shanghai Jiao Tong University

I work on code agents and evaluation methodology. My current project studies what happens to a code agent in a low-resource executable domain: a domain whose runtime cannot be redistributed, whose program correctness is defined over execution traces rather than over compilation or unit tests, and whose syntax priors are absent from public code corpora. The work builds a domain agent whose feedback loop observes real runtime behaviour, together with a benchmark whose oracle sits at the trace level and whose validity is established by mutation testing.
